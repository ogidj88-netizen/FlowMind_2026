# TOPIC QUALITY GATE V1

## Purpose
This gate checks whether a topic is good enough to enter production.

Each topic is scored on 5 criteria.
Each criterion gets:
- 0 = weak
- 1 = medium
- 2 = strong

Maximum total score = 10.

## Criteria

### 1. Pain Clarity
Is the core pain obvious and concrete?

- 0 = vague
- 1 = somewhat clear
- 2 = sharp and obvious

### 2. Market Proof
Is there evidence that this topic exists in the real market?

- 0 = weak/no proof
- 1 = one signal only
- 2 = Reddit pain + YouTube validation

### 3. Production Fit
Can this topic be turned into a usable video quickly?

- 0 = hard to shape
- 1 = possible with effort
- 2 = easy to shape into hook + structure

### 4. Specificity
Is the topic narrow and focused enough?

- 0 = too broad
- 1 = somewhat focused
- 2 = clearly specific

### 5. Actionable Utility
Will the viewer get practical value from this topic?

- 0 = mostly abstract
- 1 = some value
- 2 = strong practical value

## Decision Rule

- 8–10 = PASS
- 6–7 = BACKLOG / REVIEW
- 0–5 = KILL
